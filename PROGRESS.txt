投影统一物化方案冻结（2026-03-30）：
1) 目标范围冻结
   - `Class<T> projectionType` 统一支持：
     interface 投影、普通 DTO class 投影、record/final DTO 投影
   - 不采用 service 层二次转换；仓储层直接返回目标投影类型
   - 混合模式保持：Mapper 自定义方法优先，Projection 标准方法回退
2) 现状风险确认
   - interface 路径为 `Map(LinkedHashMap) -> 动态代理`，类型转换在 getter 调用期触发
   - 已识别高风险：`String -> Map`、`String/Number -> Enum` 在查询期正常但 getter 期失败
3) 执行顺序冻结（避免反复改动）
   - Step 0: 冻结设计决议与验收标准（仅文档）
   - Step 1: 先收敛 interface 路径，消除 getter 延迟失败
   - Step 2: 增加 record/final DTO 构造器物化能力
   - Step 3: 对齐 list/page 两条查询路径的类型转换行为
   - Step 4: 增加完整测试矩阵并回归
4) 技术策略冻结
   - 建立统一物化管线：`metadata -> row map/raw object -> pre-convert -> materialize`
   - 转换优先级：TypeHandler > 显式 Converter > ConversionService > 明确失败
   - 明确禁止“延迟到 getter 才失败”，改为物化阶段快速失败
5) Step 1 验收门槛（预设）
   - interface 投影不再在 getter 阶段抛类型转换异常
   - `String -> Map`、`Enum(name/ordinal/value)` 有稳定转换与错误提示
   - 不改变现有对外方法签名
6) 追踪与变更记录规则
   - 按增量更新 `PROGRESS.txt`
   - 同步维护根目录 `CHANGELOG.md`（Unreleased）

Projection materialization design freeze (2026-03-30):
1) Scope frozen
   - `Class<T> projectionType` will support interface, mutable DTO class, and record/final DTO.
   - No service-layer conversion.
   - Mixed mode remains: MyBatis mapped methods first, Projection fallback second.
2) Risk confirmed
   - Interface path previously used `Map(LinkedHashMap) -> proxy`, with conversion deferred to getter access.
   - High risk centered on `String -> Map` and `String/Number -> Enum` conversion.
3) Execution order frozen
   - Step 0: design freeze
   - Step 1: interface pre-conversion
   - Step 2: record/final DTO constructor materialization
   - Step 3: unify list/page semantics
   - Step 4: full regression coverage
